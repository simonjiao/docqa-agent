# 5-10 分钟演示脚本

## 1. 启动

```bash
./run.sh
```

浏览器打开 `http://localhost:8000`。

## 2. 解析 PDF

点击“加载样例 PDF”或上传作业中的 `GBT 1568-2008 键 技术条件.pdf`。

展示点：

- PDF 被识别为扫描件或混合扫描件。
- 系统选择渲染页面 + OCR 策略。
- 左侧展示 PDF 原图，右侧展示 OCR 文本。

## 3. 对比查看原图和识别内容

切换到第 3 页，点击 OCR 行，左侧高亮对应 bbox。

展示点：

- 条款编号 3、4 被识别。
- 可以通过原图核验 OCR 内容。

切换到第 4 页，点击表格候选区域。

展示点：

- 表 1 被检测为疑似表格区域。
- 当前版本对表格做候选检测，完整单元格恢复是下一轮迭代点。

## 4. 问答演示

建议输入：

1. 本标准规定了什么范围？
2. 键的抗拉强度要求是多少？
3. 表 1 中合格质量水平 AQL 和哪些检查项目有关？
4. 包装箱或盒外表面应有哪些标志？
5. 该标准是否规定了电机噪声测试？

展示点：

- 每个答案有来源页码和证据片段。
- 无答案问题应拒答。
- 自检结果显示检索分、证据覆盖、LLM 验证占位和人工复核状态。

## 5. 人工验证

对一次答案选择“通过”或“退回修正”，填写备注并保存。

展示点：

- 人工验证被记录。
- 后续可以追溯问题、答案、证据和复核意见。

## 6. 测试脚本

```bash
pytest -q
python scripts/evaluate.py --sample
```

展示点：

- 单元测试覆盖拒答、自检、chunk、PDF probe。
- 评估脚本覆盖正文、表格、无答案。
